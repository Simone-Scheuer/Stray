# Photo View Mode — Photo Density Heatmap

## What
Add a toggleable map view mode that replaces the normal fog/heat overlay with a photo density overlay — showing which cells have geotagged photos and how many, using a color gradient.

## Detailed Requirements

- Toggle button in the action bar (camera icon or similar) to enter/exit photo view mode
- When active, the fog overlay swaps to show:
  - Cells with 0 photos: dark fog (same as normal unexplored)
  - Cells with 1 photo: faint purple/magenta tint
  - Cells with 2-4 photos: medium purple
  - Cells with 5-9 photos: bright magenta
  - Cells with 10+ photos: vivid magenta/pink glow
- Use a distinct color palette from the heat gradient (so it's clearly a different mode)
- Tapping a cell in photo mode should open the cell inspector with photos visible
- Photo mode should be a simple boolean toggle on the existing FogOverlayRenderer — not a separate overlay
- Must use existing PhotoService spatial index (`photosForCell()`)
- Pattern should follow the existing timeline mode toggle (enter/exit pattern)
- Show a subtle "Photo Mode" label or indicator so the user knows the mode is active

## Constraints
- No new screens — this is a map overlay mode (same as timeline)
- Must not break existing fog rendering
- Performance: photo count lookup should be fast (PhotoService already has spatial index)

## Builder Guidance
- Certainty level: Exploratory — user said "like" suggesting the exact gradient is flexible
- The existing GridEngine + FogOverlayRenderer already handle multiple render modes (normal vs timeline). Photo mode would be a third mode.
- PhotoService.photosForCell() already exists and returns photo assets for a given GridCell
