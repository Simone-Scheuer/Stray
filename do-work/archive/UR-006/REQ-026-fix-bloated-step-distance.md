# Fix Wildly Bloated Step and Mile Count

## What

Step count and distance (miles/km) are reporting inflated values. Add sanity-check / filtering logic to prevent bloated numbers from reaching the UI and persisted stats.

## Why

The counts are "wildly" off — user-visible correctness issue affecting stats credibility.

## Context

Steps are estimated from GPS distance (`distance / 0.7`). Distance accumulates from location updates. Likely causes:
- GPS position jumps (poor accuracy, indoor signal, or app resume after background gap) producing a single large delta
- Stationary jitter accumulating tiny distances over time
- No clamping on per-update distance deltas

Possible fixes to investigate:
- Clamp per-update distance delta to a realistic max (e.g. skip if > 200m in one update — implies GPS jump, not walking)
- Already filters `horizontalAccuracy > 100m` (passive) / `> 50m` (active) — verify this is actually working
- Consider a max speed check (e.g. > 15 km/h is not walking, discard)
- Check if distance accumulates during background gaps on app resume

## Exploration

- Distance accumulation: `LocationService.swift:150-154` — `cumulativeDistance += dist` inside a `dist >= 5m` guard but no upper bound
- Steps derived: `Int(cumulativeDistance / 0.7)` recalculated on every accepted update
- `incrementalDistance` passed to `StrayApp.onLocationUpdate` callback, which persists steps to `DailySummary` via `PersistenceService.updateDailySummary`
- `horizontalAccuracy` filter (line 143) already rejects bad-accuracy fixes, but GPS jumps can occur even with good-accuracy readings after background gaps
- No existing max delta guard — any jump, however large, was accepted

## Implementation Summary

- `Constants.swift`: Added `maxDistanceDeltaMeters = 200.0` (200m implies >72 km/h over a 10s update interval — not walking)
- `LocationService.swift:150-151`: Changed single `dist >= 5m` check to `5m <= dist <= 200m` — GPS position jumps (typically 100m–1km) are now silently discarded

No stats were retroactively corrected — only future updates are filtered.
