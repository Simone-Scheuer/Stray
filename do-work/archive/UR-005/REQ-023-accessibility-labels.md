# Add VoiceOver Accessibility Labels

## What
Icon buttons, compass, and stats cards have no accessibility labels. VoiceOver users can't use the app.

## Detailed Requirements
- **ContentView action buttons** (iconButton helper, line ~103): Add `.accessibilityLabel()` for each:
  - Stray start: "Start exploring"
  - Stray end: "End exploring session"
  - Stats: "View statistics"
  - Settings: "Settings"
- **StrayCompassView**: `.accessibilityLabel("Compass pointing \(direction)")` with cardinal direction
- **Session HUD**: Label distance, duration, cells count for VoiceOver
- **StatsView cards**: Each stat card should have a combined accessibility label (e.g., "542 cells explored lifetime")
- **CellInspectorView**: Labels for visit count, dates, city
- **OnboardingView**: Ensure page content is readable in order
- **MapViewRepresentable**: The map itself should have `.accessibilityLabel("Exploration map")`

## Context
- `iconButton` helper in `Stray/Views/ContentView.swift` (line ~103)
- Compass at `Stray/Views/StrayCompassView.swift`
- Stats at `Stray/Views/StatsView.swift`
- Inspector at `Stray/Views/CellInspectorView.swift`
