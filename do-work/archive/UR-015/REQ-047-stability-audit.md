## Implementation Summary

1. **PersistenceService** — Added `backfillTask` property to track geocoding task; cancel before reassignment; added `Task.isCancelled` check in loop

5. **PersistenceService.cityCache** — Added size limit (evicts half when > 500 entries)
6. **ContentView task cancellation** — Verified already correct (no changes needed)
