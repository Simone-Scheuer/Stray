# Phase 6: Sync & Polish

## What
Verify iCloud sync works, implement deduplication, add bloom and compass animations, optimize battery, and handle all edge cases. Make the app feel polished and ready for daily use.

## Detailed Requirements

1. **iCloud sync testing**:
   - Verify `ModelConfiguration(cloudKitDatabase: .automatic)` works on real device
   - Test: reveal cells on device A → verify they appear on device B (same iCloud account)
   - Verify CloudKit container is properly configured (`iCloud.com.<team-id>.Stray`)

2. **Deduplication** (PersistenceService):
   - Run on launch and on sync completion events
   - Find `RevealedCell` records with matching `cellKey`
   - Merge: keep earliest `firstVisitedAt`, latest `lastVisitedAt`, sum `visitCount`
   - Delete duplicate records after merge

3. **Bloom animation**:
   - When a new cell is revealed, the fog should fade smoothly from dark to the heat color
   - NOT an instant pop — smooth transition is the signature micro-interaction
   - Implementation: animate the tile overlay opacity or use a staged reveal in the tile renderer

4. **Compass arrow animation**:
   - Smooth rotation interpolation between bearing updates
   - Don't snap between angles — lerp/slerp the rotation
   - Confident, fluid motion

5. **Battery optimization pass**:
   - Profile with Xcode Energy Diagnostics
   - Verify `isStationary` filtering is working (zero processing when phone is still)
   - Consider reducing tracking frequency when battery < 20%
   - Verify no unnecessary `reloadData()` calls on tile overlay

6. **Edge case handling**:
   - Fresh install: entire map is dark, no crash, onboarding flows correctly
   - Poor GPS indoors: don't falsely reveal cells (accuracy filtering handles this)
   - Airplane mode: app works offline with cached map tiles, no sync errors shown
   - App killed by OS and relaunched: data persists, tracking resumes
   - International travel: timezone changes don't break DailySummary dateString
   - Zoomed-out rendering: fog tiles render correctly at city/country scale

7. **Info.plist finalization**: All location usage descriptions, background mode declarations, CloudKit container references.

## Constraints

- Animations must not impact scrolling/panning performance
- Battery optimization is non-negotiable — this app runs 24/7
- iCloud sync must handle conflicts gracefully — never lose data
