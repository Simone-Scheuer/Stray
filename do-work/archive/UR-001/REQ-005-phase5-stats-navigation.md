# Phase 5: Stats & Navigation

## What
Implement stats aggregation engine, stats view, settings view, and bottom sheet navigation. Complete the daily loop by giving users a way to see their exploration data.

## Detailed Requirements

1. **StatsEngine.swift** — Aggregation queries against SwiftData.
   - Total cells revealed (lifetime)
   - Current streak (consecutive days with `isActiveDay == true`)
   - Total distance (sum across DailySummary records, displayed in miles)
   - Total steps (sum, estimated from distance)
   - Stray session count
   - Today's stats (cells, distance, steps)
   - **Per-city breakdown**: Group `RevealedCell` by `city` field. Return sorted by cell count descending. Format: "Portland — 4,231 cells" / "Tokyo — 342 cells"

2. **StatsViewModel.swift** — `@Observable` class. Formats stats for display. Auto-refreshes when underlying data changes.

3. **StatsView.swift** — Clean layout:
   - Big numbers for today (cells revealed, distance, steps)
   - Lifetime totals section
   - Current streak
   - Stray session count
   - Per-city breakdown list (scrollable if many cities)
   - No charts or complex visualizations in MVP — just clear, well-formatted numbers

4. **SettingsView.swift**:
   - Tracking on/off toggle
   - Location permission status display + upgrade prompt (if "When In Use", suggest "Always")
   - About section with brief philosophy blurb (Situationist inspiration, anti-optimization)

5. **ContentView.swift navigation**:
   - Map is always the primary view — it never leaves the screen
   - Bottom sheet (`.sheet` or custom) for stats and settings
   - Access via minimal UI — small icon buttons at map edge, or swipe-up gesture

6. **OnboardingView.swift polish**: 1-2 screen intro explaining the concept, permission request with context, then straight to the map.

## Constraints

- Map must never leave the screen — stats/settings are overlays
- Keep stats simple — big numbers, clean layout, no over-designed charts
- Per-city detection depends on reverse geocoding from Phase 3 — handle `nil` city gracefully ("Unknown" or skip)
