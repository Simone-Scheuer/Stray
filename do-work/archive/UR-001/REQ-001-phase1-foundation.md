# Phase 1: Foundation

## What
Create the Xcode project scaffold, all SwiftData models, utility files, and get a basic MKMapView on screen. This phase is the dependency for everything else.

## Detailed Requirements

1. **Project structure** — Create directories: `Stray/Views/`, `Stray/ViewModels/`, `Stray/Models/`, `Stray/Services/`, `Stray/Utilities/`
2. **Constants.swift** — Grid cell size (50m), search radius (500m), fog color `UIColor(white: 0.08, alpha: 0.85)`, heat gradient colors (cool blue, transparent, warm amber, bright glow), accuracy thresholds (100m passive, 50m active), average stride length (0.7m)
3. **Extensions.swift** — `CLLocationCoordinate2D` extensions: distance between two coordinates (Haversine), geographic bearing calculation
4. **GridCell.swift** — `struct GridCell: Hashable, Codable, Sendable`. Custom lat/lng grid with ~50m cells. `latStep = 50.0 / 111_320.0`. `lngStep` computed per-latitude using `cos(lat)`. `from(latitude:longitude:)` factory. `coordinate` property returning SW corner. `key` string property.
5. **RevealedCell.swift** — SwiftData `@Model`. Properties: `latIndex: Int = 0`, `lngIndex: Int = 0`, `cellKey: String = ""`, `firstVisitedAt: Date = Date()`, `lastVisitedAt: Date = Date()`, `visitCount: Int = 1`, `city: String? = nil`. All properties have defaults (CloudKit requirement). NO `@Attribute(.unique)`. Indexed on `cellKey`, `latIndex`, `lastVisitedAt`, `city`.
6. **StraySession.swift** — SwiftData `@Model`. Properties: `startedAt: Date = Date()`, `endedAt: Date? = nil`, `cellsRevealedCount: Int = 0`, `distanceMeters: Double = 0.0`, `durationSeconds: Double = 0.0`, `pathData: Data? = nil`.
7. **DailySummary.swift** — SwiftData `@Model`. Properties: `dateString: String = ""`, `cellsRevealed: Int = 0`, `distanceMeters: Double = 0.0`, `stepCount: Int = 0`, `isActiveDay: Bool = false`.
8. **StrayApp.swift** — `@main` entry point. Create `ModelContainer` with `ModelConfiguration(cloudKitDatabase: .automatic)` for all three models. Initialize services and inject via `.environment()`.
9. **MapViewRepresentable.swift** — `UIViewRepresentable` wrapping `MKMapView`. Show user location (`showsUserLocation = true`), follow user (`userTrackingMode = .follow`). Coordinator as `MKMapViewDelegate`.
10. **ContentView.swift** — Full-screen `MapViewRepresentable`. No chrome yet.
11. **Info.plist** — `NSLocationWhenInUseUsageDescription` and `NSLocationAlwaysAndWhenInUseUsageDescription`.
