# Session Pause/Resume

## What
Add a pause button to Stray/Derive sessions. Pausing stops location tracking and the session timer without ending the session. Resume picks up where you left off.

## Context
User has accumulated many short sessions because ending a session is the only way to stop tracking (e.g., stopping for coffee). This is the highest-priority item — fixes an active pain point.

## Requirements
- Pause button in the session HUD (replaces or sits alongside the End button)
- Pausing stops the location stream and freezes the session timer
- Resuming restarts location tracking and continues the timer
- Session summary shows total active time (excluding paused time)
- StraySession model needs a `pausedDuration` or similar field to track cumulative paused time
- Compass hides while paused, reappears on resume
- Path trace (REQ-039) should show a gap during paused segments if both are built

## Builder Guidance
- Certainty level: Firm — user explicitly wants this
- Keep UI minimal: one button toggles pause/resume state
